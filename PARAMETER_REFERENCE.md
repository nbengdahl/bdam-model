# Scientific parameter reference

Generated by `tools/update_parameter_reference.py` from
`bdam_parameter_schema.json` (bdam-parameters-v6). Do not edit the tables by hand.
See [PARAMETERS.md](PARAMETERS.md) for overrides, arrays, automatic values and migration.

The units are meters and days. Each row is an accepted scientific field; study
capacity, retention and the MATLAB executable belong to execution settings.
Automatic values are resolved after shared settings and case overrides.

General interactions: layer-property arrays match `n_layers`; the dam leakage
layer count cannot exceed it. Automatic boundary K follows `K_constant`.
UZF water contents must satisfy residual < saturated, with initial/ET contents
within their permitted ranges. Monthly arrays are January–December. Geometry
must fit the channel/meander and contain integer cell counts. Preparation can
reject geometric combinations even when individual fields meet their bounds.

Registry defaults and the MATLAB defaults mirror must remain consistent.
Removed intermediate width/depth/preview controls are not accepted; river pool
initial depth is fixed at 0.10 m and installation conserves inherited volume.

## Automatic defaults

- `K_by_layer_top_to_bottom`: 0.03 repeated n_layers times.
- `K33_by_layer_top_to_bottom`: 0.003 repeated n_layers times.
- `groundwater_boundary_k_m_per_day`: K_constant.
